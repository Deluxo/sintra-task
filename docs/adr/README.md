# Architecture Decision Records

This directory records the architectural decisions made for this project.

## Format

Each ADR follows a lightweight MADR-style format:

- **Status** — `Accepted`, `Deferred`, `Superseded by ADR-XXXX`, etc.
- **Date** — the date the decision was made
- **Context** — the problem and constraints
- **Decision** — what was decided
- **Consequences** — positive, negative, and constraints
- **Alternatives Considered** — options that were rejected and why

Some entries are **notices** rather than decisions (e.g. 0009); they carry the
same headers but record context instead of a decision.
